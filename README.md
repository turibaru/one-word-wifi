## How it works

`main.ts` reads `entry.txt` at runtime and writes its exact contents to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The entry is a single word (1–20 characters,
no whitespace); the program exits non-zero if the entry is empty, longer than
20 characters, contains whitespace, or `MAKEFUN_OUTPUT_DIR` is not set.
